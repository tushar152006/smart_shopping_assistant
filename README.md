# Smart Shopping Assistant

An AI-powered shopping assistant focused on forgotten-item prevention, built in careful phases with a free-first stack.

## Project Goal

Help users avoid forgetting essential shopping items by combining:

- Interpretable recommendation logic
- Clear natural-language explanations
- A lightweight full-stack web app

## Build Strategy

We will build this project phase by phase instead of trying to build everything at once.

Current planning docs:

- `docs/PROJECT_ROADMAP.md`
- `docs/PHASE_1_FOUNDATION.md`

## Proposed Core Stack

- Frontend: React + Vite
- Backend: FastAPI
- Database: SQLite first, PostgreSQL later if needed
- ML: pandas, scikit-learn, mlxtend
- Explainability: rule templates first, optional LLM layer second
- Deployment: Vercel for frontend, lightweight backend deployment later

## Guiding Principles

- Start with an MVP before advanced research features
- Keep the system interpretable first, clever second
- Use free tools where possible
- Validate each phase before moving to the next
